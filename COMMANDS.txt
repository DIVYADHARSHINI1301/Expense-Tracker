# 🎯 QUICK COMMANDS - Copy & Paste

## 🚀 Deploy in 3 Commands

### 1️⃣ Generate Icons
```bash
# Double-click this file:
generate-icons.bat

# OR open in browser:
icon-generator.html
```

### 2️⃣ Deploy App
```bash
# Double-click this file:
deploy.bat

# OR run manually:
npm run build
vercel --prod
```

### 3️⃣ Install on Mobile
```
1. Open URL on mobile
2. Tap "Add to Home Screen"
3. Done! 🎉
```

---

## 📦 Manual Deployment Commands

### Vercel (Recommended)
```bash
npm install -g vercel
npm run build
vercel --prod
```

### Netlify
```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod
```

### Firebase
```bash
npm install -g firebase-tools
firebase login
npm run build
firebase deploy --only hosting
```

## 🆘 Quick Fixes

**Build Error:**
```bash
npm install
npm run build
```

**Deploy Error:**
```bash
vercel login
vercel --prod
```

**Icons Not Showing:**
```bash
# 1. Check icons in public/
# 2. Rebuild
npm run build
# 3. Redeploy
deploy.bat
```
