
2. **Double-click it** - A command window will open

3. **Choose deployment platform:**
   - Type `1` and press Enter for **Vercel** (Recommended - Fastest)
   - Type `2` and press Enter for **Netlify**

4. **Wait for deployment** (30-60 seconds)

5. **Copy your live URL** from the command window

### Your URL will look like:
```

Firebase: https://expense-tracker-f604a.web.app
```

## 🆘 TROUBLESHOOTING

### Problem: Can't find deploy.bat
**Solution:** Look in your project folder: `expense-tracker/deploy.bat`

### Problem: Icons not downloading
**Solution:** 
1. Open `icon-generator.html` directly in browser
2. Right-click each icon → "Save image as..."
3. Save to `public/` folder

### Problem: Deploy fails
**Solution:**
1. Make sure you have internet connection
2. Try different platform (type 1, 2, or 3)
3. Run: `npm install` then try again

### Problem: Can't add to home screen
**Solution:**
- Make sure you're using the HTTPS URL (not localhost)
- Try in incognito/private mode
- Clear browser cache
- Try different browser

### Problem: Icon not showing after install
**Solution:**
1. Check all 8 icons are in `public/` folder
2. Run `deploy.bat` again
3. Uninstall old app from phone
4. Reinstall from new URL
